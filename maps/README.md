# Резервная PMTiles-подложка

Публичная «Карта отзывов» умеет использовать собственные PMTiles-файлы без внешнего тайл-сервера.

Ожидаемые файлы по умолчанию:

- `maps/moscow.pmtiles` — Москва и Московская область
- `maps/spb.pmtiles` — Санкт-Петербург и Ленинградская область

Файлы можно подготовить через российский сервис OSM2CDR:
https://osm2cdr.ru/formats/pmtiles/

Рекомендуемый охват: вся территория, в которой расположены объекты сети. После загрузки файлов в эти пути внешний интерфейс автоматически использует их, если Яндекс недоступен.

Если файлы отсутствуют, последним резервом остаётся интерактивный список объектов.
