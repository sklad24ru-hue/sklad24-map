# Yandex Tiles API branding

Для активации режима Yandex Tiles API положите официальный логотип Яндекса в:

`assets/yandex-logo.png`

Получить официальный комплект логотипов нужно из документации Tiles API:
https://yandex.ru/maps-api/docs/tiles-api/

Страница намеренно НЕ включает Tiles API, пока официальный файл логотипа отсутствует: документация требует отображать кликабельный логотип Яндекса поверх карты.

После добавления логотипа и ключа Tiles API режим включится автоматически.
