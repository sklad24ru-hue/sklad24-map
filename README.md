# Карта отзывов

Нейтральная внешняя карта отзывов с интерактивными объектами, рейтингами и фильтрами.

## Архитектура

- Предпочтительный основной источник подложки: Yandex Tiles API.
- Временная совместимость до настройки Tiles API: Yandex Maps JavaScript API 3.0.
- Автономный резерв: собственные PMTiles-файлы, размещённые рядом с GitHub Pages.
- Последний резерв: интерактивный список объектов без картографической подложки.
- Данные объектов и отзывов: `map-data.json`.
- Google Apps Script публикует свежий снимок данных.
- Telegram открывает обычный HTTPS-адрес GitHub Pages.
- В публичные данные не должны попадать ответственные сотрудники, внутренние токены и служебные поля.
